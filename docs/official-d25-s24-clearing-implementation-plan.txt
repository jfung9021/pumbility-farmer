4. Numerical policy

Use the following existing D26 rules for each new folder:

  a. Build histories separately for each mode. D25 uses D23+ histories; S24
     uses S22+ histories, matching the existing official Singles contract.
  b. Exclude the target chart. Require at least 25 other distinct observed
     official clears, and average the highest 25 current level midpoints L+0.5.
  c. Take the linearly interpolated 20th percentile of eligible clearer ability.
  d. With n eligible and N observed unique clearers, use weight
           n/(n+20) * n/N
     and raw delta
           0.70 * weight * (chart q20 - uncapped folder median q20).
  e. Reuse robust folder-spread calibration. Five qualifying charts, each with
     at least ten eligible clearers, support an independent folder scale.
     Retain same-mode neighboring-scale or scale-1 fallback and weaker evidence
     when unsupported. Never let new folders change old D26+ donor selection.
  f. Preserve P1_OBSERVED_CAP_POLICY: Phoenix 1 caps remain diagnostic and affect
     evidence status; Phoenix 2 truncation triggers the existing cap default.
     Assign capped charts the uncapped folder minimum, or midpoint if none is
     available. Do not invent confidence intervals for cap assignments.
  g. Recenter finite core estimates to L+0.5, then apply the artifact's midpoint
     compression exactly once. Preserve initial-fit and recentering diagnostics.
  h. Apply the existing final_folder_width policy to the NEW folders only,
     including the protected median-pair behavior, cap exclusion from the fit
     population, transformed endpoints, and sparse-population evidence flags.
  i. Recompute Clearing ranks and General/SSS/SSS+ Pumbility within each affected
     mode/folder. Each Pumbility value is the full-precision mean of unchanged
     final Scoring and new final Clearing; both components remain required.

Keep deterministic 1,000-sample conditional q20 bootstrap behavior. Histories,
folder reference, spread, recentering, and width remain fixed. Preserve sparse
interval-unavailable reasons and the existing conditional Pumbility convention;
do not label these as joint intervals for both components.

S22+ feasibility: the audit found median S24 eligible support of 256.5 across
the 30 catalog charts and median observed-board coverage of 88.10%. Existing
D23+ histories gave D25 median eligible support 154.5 and coverage 94.318%
under the current exclusion policy. No reduced eligibility requirement is needed.

Median checks must use the population each stage actually declares. Core
recentering includes all finite assignments. The supported final width fit
excludes cap defaults, so its uncapped population median is the protected one.
With capped boards, the final all-chart median need not equal the uncapped
median. Report both instead of imposing contradictory guarantees.
